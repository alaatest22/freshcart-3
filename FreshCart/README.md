# FreshCart

مشروع React + Vite مكتمل داخل تقسيمة `src/Components` الأصلية، مع واجهة إنجليزية متجاوبة.

## التشغيل

استخدم Node.js **22.12 أو أحدث** (تم البناء باستخدام Node 24).
افتح Terminal داخل فولدر FreshCart الذي يحتوي على `package.json`:

```bash
npm ci
npm run dev
```

افتح الرابط الذي يظهر في Terminal. لا تفتح `index.html` مباشرة.
النسخة لا تحتوي على `node_modules`؛ الأمر `npm ci` يثبت المكتبات المناسبة لجهازك.

```bash
npm run lint
npm run build
npm run preview
```

## ما تم تنفيذه

- Home: بانر، تصنيفات، منتجات وروابط تنقل.
- Products: بحث، تصفية حسب التصنيف والبراند، ترتيب، وتقسيم صفحات من السيرفر.
- ProductDetails: صور قابلة للاختيار، وصف، سعر، توافر، إضافة للسلة والمفضلة.
- Brands / Categories: قوائم من الـAPI، تقسيم صفحات، والضغط يفتح منتجات العنصر.
- Register / Login: فحص مدخلات، رسائل سيرفر، حفظ جلسة، والرجوع للصفحة المطلوبة بعد الدخول.
- ForgotPassword: إرسال كود، التحقق منه، تغيير كلمة المرور.
- Account: تغيير كلمة مرور المستخدم المسجل.
- Wishlist: حفظ وحذف المفضلة وإضافة المنتجات للسلة.
- Cart: إضافة، تعديل الكمية، حذف عنصر، تفريغ السلة، والإجمالي من السيرفر.
- Checkout: عنوان ورقم هاتف، دفع كاش أو الانتقال لصفحة الدفع المستضافة.
- Orders: عرض الطلبات وحالتي الدفع والتوصيل من السيرفر وزر تحديث.
- حماية المسارات الخاصة، تسجيل خروج، معالجة انتهاء الجلسة، عدادات السلة والمفضلة.
- حالات تحميل، فشل، قائمة فارغة، محاولات إعادة تحميل، وإلغاء طلبات القراءة القديمة.
- منع ضغطات متزامنة على تعديلات السلة والمفضلة، ومعالجة الصور غير المتاحة.
- إعدادات SPA لـVercel وNetlify.

## تقسيمة الكود

| المكان | المسؤولية |
| --- | --- |
| `src/App.jsx` | المسارات وحمايتها والصفحة غير الموجودة |
| `src/Components` | الصفحات ومكونات العرض |
| `src/Context/Providers.jsx` | جلسة المستخدم، السلة، المفضلة، والإشعارات |
| `src/Context/contexts.js` | تعريف Context والـhooks المستخدمة للوصول إليه |
| `src/lib/api.js` | طلبات fetch، التوكن، أخطاء السيرفر، تنسيق العملة |
| `src/hooks/useResource.js` | قراءة البيانات مع الإلغاء وإعادة المحاولة |
| `src/index.css` | جميع تنسيقات الكمبيوتر والموبايل |

لم تتم إضافة Tailwind أو Axios لأنهما غير موجودين في المكتبات الأصلية؛ استُخدم CSS عادي و`fetch` المدمج. لا تحتاج API key للمنتجات. ينشأ التوكن من حسابك في API الكورس.

## الـAPI والدفع

الافتراضي: `https://ecommerce.routemisr.com/api/v1`.
لو احتجت تغييره انسخ `.env.example` إلى `.env` ثم عدّل `VITE_API_URL` وأعد تشغيل Vite.

- الـheader للمسارات المحمية هو `token` حسب توثيق FreshCart.
- التوكن محفوظ تحت `freshcart.token` لتجنب خلطه بتوكن مشروع السوشيال ميديا.
- الدفع الإلكتروني ينشئ session من `/orders/checkout-session/:cartId` ويرسل أصل الموقع الحالي في `url`، ثم يفتح الرابط الذي أعاده السيرفر.
- صفحة `/allorders` موجودة لاستقبال المستخدم بعد الدفع. ظهور الصفحة لا يعني نجاح الدفع؛ حالة `isPaid` تأتي من API الطلبات. حدّث الحالة بعد عودتك من الدفع إذا تأخرت معالجة السيرفر.
- لم توضع بيانات بطاقة أو مفاتيح سرية في الكود. لا تنفذ بيانات دفع حقيقية قبل التأكد من وضع الاختبار لدى مزود API الكورس.
- الكاش يرسل الطلب للسيرفر عند الضغط على Place cash order، ثم يفرغ السلة محليًا بعد نجاح الرد.

## التحقق وحدوده

تم التحقق من البناء وESLint، والوصول الفعلي لقراءة المنتجات والتصنيفات والبراندات، واختبارات المتصفح باستخدام ردود API محاكاة للعمليات الخاصة بالحساب والسلة والطلبات والدفع.
لم يُنشأ حساب حقيقي ولم تُنفذ عملية دفع أو طلب شراء حقيقي أثناء التطوير. اختبر حسابك وبوابة الدفع التجريبية قبل التسليم.
تعذر فتح ملف Figma؛ التصميم مستوحى من ديمو FreshCart المرفق، وليس ادعاء مطابقة حرفية. محتوى سيشن الانستراكتور غير مرفق، لذا راجع قائمة المتطلبات معه لأي تفاصيل إضافية غير المذكورة في التكليف.

```bash
npx playwright install chromium --only-shell

```

الاختبار يشغّل Vite بنفسه على المنفذ 5173، ويستخدم ردودًا محاكاة دون كتابة بيانات في API الحقيقي. أغلق أي سيرفر يستخدم هذا المنفذ قبل تشغيله.

## النشر

- Vercel: إطار Vite، أمر البناء `npm run build`، وفولدر الناتج `dist`. ملف `vercel.json` يعالج المسارات المباشرة.
- Netlify: نفس أمر البناء والناتج، مع ملف `public/_redirects`.
- بعد النشر راجع تسجيل الدخول وفتح `/products/:id` مباشرة، ثم اختبر الرجوع من الدفع إلى `/allorders` على نفس الدومين.
